## 📜 Background and Origin

This pipeline was originally **developed and utilized** for the study by:  

✍️ Kumar, P., Morbia, I., Satish, A. L., Datta, S., & Singh, U. (2025). *CGGBP1 from higher amniotes restricts cytosine methylation and drives a GC-bias in transcription factor-binding sites at repressed promoters.* 📖 **Transcription, 1–36.** 🔗 [https://doi.org/10.1080/21541264.2025.2533598]   

> ⚠️ *Note:* While the analysis extensively utilized this pipeline, **the original scripts were not publicly submitted** alongside the publication.  

---

## 📂 Repository Significance

✨ Along with the **MAP-MAP pipeline**, we have also developed a concise pipeline for analyzing the **G4 landscape** of vertebrate genomes.  

📁 This repository contains the **official submission** of both pipelines' script collections, enabling:  
- 🔄 Reproducibility  
- 🔍 Transparency  
- 🚀 Further use by the scientific community in methylation, mutation, and G4 structure analyses
